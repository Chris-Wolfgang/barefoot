# v1 UI mockup (WPF era, July 2026)

`ui-mockup.html` is the eight-screen HTML mockup the v1 WPF screens were built from (DESIGN v1 §10).
The published artifact it came from no longer exists; this copy was **reconstructed on 2026-11-06 from
the 2026-07-03 design-session transcript** by replaying the file's write and 44 edits — 40 applied
cleanly, 4 late text edits could not be matched, so a label or two may differ from the approved version.
The screens and layout are faithful.

Kept as design history only. The v2 (web) UI is designed from scratch — see DESIGN v2 §12 and ADR 0008.
